---
title: Requirements
description: The REAPER version and the one extension AutoColor needs
---

| | |
|---|---|
| REAPER | **7**, tested against 7.80 on macOS/arm64 and Windows 10 |
| ReaImGui | **0.10 or later**, for the configuration window only |

To install ReaImGui: *Extensions → ReaPack → Browse packages*, search `ReaImGui`, **Install**,
restart REAPER.

## Where to go next

- [Installation](/Reaper-AutoColor/installation/) — install through ReaPack, or copy the folder in by hand.
